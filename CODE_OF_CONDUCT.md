# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussion about the code and
the documentation. Harassment, personal attacks and sharing others' private information (including
recordings or transcripts of anyone's meetings) are not tolerated.

Report unacceptable behavior privately to the maintainer ([@damianpeaf](https://github.com/damianpeaf))
through GitHub. Reports are handled confidentially. Maintainers may remove comments, issues or
contributions that violate this code.
